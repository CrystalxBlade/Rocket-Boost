## 💭 About the Game

Rocket Boost is a 3D physics-driven rocket navigation game inspired by classic movement-based challenges.

Control a futuristic rocket across dangerous space environments filled with obstacles, rotating hazards, narrow landing zones, and deadly collisions.

The objective is simple:

- Reach the finish platform safely
- Avoid crashing into obstacles
- Master rocket movement and momentum
- Complete increasingly difficult levels

Every level becomes a tiny orbital exam where gravity, timing, and patience try to humble the player 🚀

---

## ✨ Features

- 🚀 Physics-based rocket movement
- 🌌 Space-themed environments
- 💥 Crash & success particle effects
- 🔊 Audio system with music + SFX controls
- ⏸ Pause menu system
- 🧠 Level progression using PlayerPrefs
- 🎮 New Unity Input System
- ☁️ Atmospheric sci-fi visuals

---

## 🎮 Controls

| Action | Key |
|--------|-----|
| Thrust   | Space |
| Rotate Left   | A |
| Rotate Right | D |
| Pause  | ESC |
| Debug Next Level  | L |

## 🚀 How to Play
```
1. Download the game from itch.io  
2. Extract the ZIP file  
3. Run `RocketBooster.exe`

⚠️ Windows might act a little dramatic and say “this app looks suspicious” 😤  
Don’t worry — it’s just because the game is new.

👉 Click **More info → Run anyway** and enjoy!
```
